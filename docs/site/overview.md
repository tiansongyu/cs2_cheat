# 项目概览

项目把 Windows 覆盖层、游戏状态快照和浏览器 Radar 放在同一仓库中。可以从内存结构、坐标投影、实时渲染和网络快照分发几个方向阅读代码。

## 功能范围

| 模块 | 仓库中的实现 |
| --- | --- |
| ESP 覆盖层 | 方框、骨骼、血条、武器、距离、射线、spotted 状态、手雷和掉落武器 |
| 辅助功能 | 自动瞄准、FOV 与平滑度调节、自动扳机、炸弹计时；防闪光写入默认关闭 |
| 本地枪械皮肤 | 普通枪械皮肤、磨损、种子、预设保存、参数读回与关闭恢复 |
| 固定地图 Radar | 北向地图、玩家朝向、楼层、队伍面板、装备与 C4 状态 |
| 共享与回放 | 内嵌 Web 服务、可信局域网访问、公网 Relay、脱敏 NDJSON 录制 |
| 性能诊断 | 自适应采样、慢客户端背压、采样与渲染耗时、RPM、P95/P99 统计 |

## 运行条件

Windows 主程序需要 Windows 10/11 x64。游戏窗口应采用全屏窗口化模式，并完整位于单个显示器内；跨显示器时覆盖层暂停渲染，窗口恢复后继续。独占全屏不受支持。

启动时会请求管理员权限，程序可以在游戏重启后重新连接。默认 `F4` 打开或隐藏菜单，`F9` 退出。运行日志位于 `%TEMP%\cs2-esp.log`。

## 本地换皮的状态与限制

当前分支的第一版目录包含 34 种普通枪械、1,448 个武器与皮肤组合。刀、手套、贴纸、挂件和 StatTrak 不在此版范围内。实现不修改账户库存。

换皮需要显式允许内存写入；选择保存在 `%LOCALAPPDATA%\AegisCS2\skins-v1.ini`，重启后开关仍保持关闭。命名预设保存在同目录下的 `skin-presets` 文件夹。

参数修改先进入草稿，点击 **Apply & save** 后才更新方案。关闭时仅恢复仍由本地玩家持有、身份有效且字段未被游戏替换的实体。

```{important}
参数读回成功只说明写入值一致。实际材质刷新仍需在 Windows 离线局中验收，不能把自动测试结果当作游戏画面验证。当前文档描述的是源码状态，发布包可能滞后。
```

## 版本与许可

偏移版本记录在仓库根目录的 `last_commit.txt`；构建会生成诊断元数据。偏移文件更新后仍需验证游戏兼容性。
