CS2 正式公网 Radar 架构

同一份不可变 JSON v1 快照，独立服务本机 CivetWeb 与公网 WSS Relay；游戏电脑只建立出站连接

最小公网攻击面

  • • 游戏电脑不监听公网端口，只主动建立经系统证书校验的 WSS
  • • 公网只开放 Caddy 的 80/443，Go Relay :8080 仅存在于内部 bridge
  • • Producer bearer、Viewer invite 与短期浏览器 Session 权限相互分离

实时状态与背压

  • • 每个房间只允许一个 Producer，并只保存一份仍在 TTL 内的最新快照
  • • 每个 Viewer 使用容量为一的发送槽；慢客户端跳过旧帧而不拖慢采样
  • • 帧大小、发布频率、时间新鲜度、登录速率与会话连接数均受限

一份 UI，两种独立部署模式

  • • 本机 CivetWeb 与公网 Relay 共享同一不可变 GameSnapshot / JSON v1
  • • embedded token 链路和公网 Cookie 链路可分别启停，也可以同时工作
  • • 公网 Relay 不写快照、不提供历史或回放；重启即清空会话与最新帧
